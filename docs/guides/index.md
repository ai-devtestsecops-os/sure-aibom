# 가이드

aibom-cli 의 설치와 사용법, 그리고 스캔이 무엇을 받아 무엇을 찾고 무엇을 내는지 설명한다.

- **[시작하기](getting-started.md)**: 설치부터 첫 AI-BOM 까지 한 번에 따라간다. 설치, 생성, 출력 확인, 검증 순이다.
- **[스캔 대상](scan-targets.md)**: 입력으로 받는 디렉터리, 컨테이너 이미지, 이미지 아카이브, 로컬 데이터를 어떻게 판별하고 어떻게 받아 푸는지 설명한다.
- **[수집 항목](collected-items.md)**: 각 도구가 스캔 대상 안에서 어떤 파일을 읽는지, 로컬 데이터를 어떤 단위로 묶는지 BOM 별로 설명한다.
- **[출력 포맷](output-format.md)**: `--spec` 으로 고르는 두 출력 포맷의 차이와 공통 구조를 설명한다.
