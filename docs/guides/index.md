# 가이드

aibom-cli 의 설치와 사용법, 그리고 스캔이 무엇을 찾는지 설명한다.

- **[시작하기](getting-started.md)**: 설치부터 첫 AI-BOM 까지 한 번에 따라간다. 도구 환경을 갖추고, 디렉터리와 컨테이너 이미지를 스캔하고,
  출력된 문서를 읽고, 규제 필드 형식을 고르고, 스키마로 검증하는 명령을 다룬다.
- **[스캔 대상](scan-targets.md)**: 입력으로 받는 디렉터리, 컨테이너 이미지, 이미지 `.tar`, 로컬 데이터마다 소프트웨어 패키지, 모델,
  데이터셋을 어디서 어떤 규칙으로 찾는지, 그리고 무엇을 건너뛰는지 설명한다.
