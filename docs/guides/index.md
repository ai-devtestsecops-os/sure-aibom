# 가이드

aibom-cli 의 설치와 사용법, 그리고 스캔이 무엇을 받아 무엇을 찾고 무엇을 내는지 설명한다.

- **[시작하기](getting-started.md)**: 설치부터 첫 AI-BOM 까지 한 번에 따라간다. 설치, 생성, 출력 확인, 검증 순이다.
- **[스캔 대상](scan-targets.md)**: 입력으로 받는 디렉터리, 컨테이너 이미지, 이미지 `.tar`, 로컬 데이터를 어떻게 판별하고 어떻게 받아 푸는지 설명한다.
- **[수집 항목](collected-items.md)**: 스캔이 소프트웨어 패키지, 모델, 데이터셋을 어떤 파일에서 어떤 규칙으로 찾는지, 그리고 무엇을 건너뛰는지
  BOM 별로 설명한다.
- **[출력 포맷](output-format.md)**: 결과 문서의 구조(루트 컴포넌트, 컴포넌트 종류, 모델 카드와 데이터셋 정보의 자리)와 `--spec` 으로
  고르는 두 가지 규제 필드 자리, jq 로 꺼내 보는 법을 설명한다.
