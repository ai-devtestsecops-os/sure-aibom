# aibom-cli

aibom-cli 는 syft, cdxgen, OWASP aibom-generator 를 활용해 데이터셋·모델·소프트웨어 BOM(D/M/S-BOM)을 생성한다.
디렉터리와 컨테이너 이미지를 스캔해 AI-BOM 을 CycloneDX 문서 하나로 내는 CLI 도구다.

| 문서 | 내용 |
|---|---|
| [스캔 대상](scan-targets.md) | 무엇을 입력으로 받고, 그 안에서 무엇을 찾는지 |
| [필드 매핑 뷰어](field-mapping.md) | CycloneDX · SPDX 필드 대응과 AI-BOM 이 더한 필드 |

설치와 명령은 저장소의 README 를 참고한다.
